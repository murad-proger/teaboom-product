# Teaboom — карточка товара

Вёрстка блока карточки товара интернет-магазина Teaboom.ru («Ананасовый улун») на чистых HTML, CSS и JavaScript.

**Демо:** [ССЫЛКА-НА-GITHUB-PAGES](https://murad-proger.github.io/teaboom-product/)

## Что внутри

- Галерея: главное фото и миниатюры. Если миниатюр больше трёх, включается слайдер [Swiper](https://swiperjs.com/). Просмотр фото в модальном окне через [PhotoSwipe](https://photoswipe.com/).
- Фасовки (100 / 500 / 1000 / 5000 г): при выборе меняются цена, старая цена и артикул, показывается счётчик нажатий и уведомление «Товар добавлен в корзину».
- Кнопка «В корзину» и кнопка «нравится».
- Табы «Описание», «Свойства», «Отзывы».
- Адаптивность: десктоп (1440 px), планшет (768 px), мобильные (375 px).

## Структура

```
index.html   — разметка
style.css    — стили (брейкпоинты в конце файла)
script.js    — логика
```

## Запуск

Откройте `index.html` в браузере. Для работы Swiper и PhotoSwipe нужен интернет (подключены через CDN).
